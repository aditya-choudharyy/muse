# Muse

### An infinite canvas for thoughts that don't fit into folders.

Muse is a browser-based visual workspace designed to help you capture, explore, and connect ideas without interrupting your creative process.

Instead of organizing everything into rigid lists and documents, Muse gives you an open canvas where thoughts can take shape visually.

## Features

- **Infinite Canvas** — A large workspace with pan and zoom controls.
- **Text & Notes** — Capture thoughts and organize information visually.
- **Media Support** — Add images, videos, audio, and sketches.
- **Visual Connections** — Connect related ideas on the canvas.
- **Image Tools** — Crop, annotate, and extract colour palettes.
- **Organization** — Group, select, align, and arrange elements.
- **Audio Recording** — Record audio directly in your workspace.
- **Import & Export** — Export and restore projects, including their media.

## Getting Started

Muse is a standalone web application. There is no build process or package installation required.

1. Clone the repository:

   ```bash
   git clone https://github.com/aditya-choudharyy/muse.git
   ```

2. Open `index.html` in your browser.

Alternatively, use the [live version](https://aditya-choudharyy.github.io/muse/).

## Data & Storage

Muse stores project data locally in your browser using IndexedDB.

- No account is required.
- Projects are stored in your browser.
- Export your projects regularly to keep backups.
- Clearing browser data may remove locally stored projects.

## Browser Permissions

Some features, such as audio recording, require browser permissions. Media playback and external fonts may also require an internet connection.
